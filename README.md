# FDE Lab: Python & Production Engineering

A ready-to-use coding environment. Nothing to install on your laptop.
It includes Python 3.12, Git and Docker.

## Get started (about 3 minutes)

1. Create a free account at https://github.com if you don't have one.
2. Click this link: https://codespaces.new/priyankasah25/fde-lab
3. Click **Create new codespace** and wait 3 to 5 minutes.
4. In the terminal at the bottom, run:

   ```
   bash check_setup.sh
   ```

5. If you see **All good. You are ready for the session.**, you are done.

## If something goes wrong

- Make sure you are signed in to GitHub.
- If the page stays blank, refresh the browser tab.
- If `docker` is not found, press `Cmd/Ctrl + Shift + P`, type `Full Rebuild Container`, and press Enter.
- Company laptop blocking github.com? Use a personal device for this session.
- Still stuck? Tell the trainer before the session.

## Notes

- A codespace stops after about 30 minutes of inactivity. Reopen it from https://github.com/codespaces.
- Free accounts have a monthly allowance of Codespaces hours. Delete the codespace when you finish.
